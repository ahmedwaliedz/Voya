# VOYA Illustration Layer Prep

Use this skill for Phase 2. Keep the approved artwork intact and make only the layers needed for the approved motion plan.

## Boundaries

- Preserve faces, glasses, expressions, proportions, silhouettes, colors, and line weight.
- Do not invent hidden geometry, angles, poses, or 3D depth.
- Keep the artwork 2D and layer-ready.

## Work

1. Record the source path, canvas size, aspect ratio, and visible overlaps.
2. Separate only the layers needed for the approved motion.
3. Keep enough hidden overlap for the approved motion range.
4. Remove stray pixels and excess transparent padding.
5. Export stable dimensions or viewboxes.
6. Reassemble with motion disabled in a browser.
7. Compare at source, desktop, and mobile sizes.
8. Test the smallest approved motion range.
9. Record the layer list, pivots, sizes, fallback, and evidence.

## Minimum layer set

- Base body or pose.
- Head only when separate movement is needed.
- Arm and hand only when separate movement is needed.
- Plate or cup.
- Ingredients, coffee beans, or steam.
- Shadow.
- Simplified mobile fallback when required.

## Output

- Source and export paths.
- Layer list and intentionally merged layers.
- Format, dimensions, bytes, and padding result.
- Pivot and transform-origin result.
- Reassembly comparison result.
- Mobile fallback and accessibility result.
- Exact evidence paths.
- Final decision: Ready for Phase 3, Needs revision, or Blocked.
